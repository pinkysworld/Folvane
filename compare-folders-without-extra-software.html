Compare two folders on Windows without extra software

You do not need to install anything to see how two folders differ. Windows already has three ways to do it. Each has limits, which is where a dedicated tool can help.

1. File Explorer: a rough check

Select all in each folder, right-click, Properties: you get the number of files and the total size. If the numbers differ, the folders differ. If they match, they might still differ, because the same size does not mean the same content. It also does not tell you which files are different.

2. robocopy: what is missing

robocopy "C:\A" "D:\B" /L /E /NJH /NJS /NP

/L lists without copying, /E includes subfolders. The output shows files that are missing or older in B. It looks in one direction only, so run it again with A and B swapped for the other side.

3. PowerShell: both directions

Compare-Object (Get-ChildItem "C:\A" -Recurse -File -Name) (Get-ChildItem "D:\B" -Recurse -File -Name)

The result lists names with an arrow: <= only in A, => only in B. This compares file names only. To compare content, add Get-FileHash for each file, which is slower and takes more typing.

Frequently asked questions

Can I compare two folders in File Explorer?

Only roughly: you can compare file count and total size in Properties. It does not show which files differ.

Does robocopy compare both directions?

No. It works from a source to a target. Run it again with the folders swapped to see the other direction.

Does PowerShell compare file contents?

Compare-Object on names does not. For content, compute a hash per file with Get-FileHash and compare those.

Does Folvane change anything while comparing?

No. Comparing only reads. Nothing is copied or removed before you confirm a previewed sync.
