Compare folders on Windows

Windows Explorer shows you folders one at a time. To find out how two folders differ you need to see them side by side, file by file. Folvane does that and lets you act on the result.

What you see

Both folders are listed together. Each file has a state: identical, left only, right only, left newer, right newer or different. Color filters and instant search help in large folders, and sub-folders are included.

How files are compared

Quick mode compares size and modification date and finishes in seconds. Byte-by-byte mode reads the content and tells you for sure whether two files are the same. You can include only certain types such as *.jpg; *.docx or exclude patterns such as node_modules; .git; *.tmp.

Looking inside files

Double-click a changed text file for a side-by-side text diff with changed, added and removed lines highlighted; F8 jumps to the next change. A duplicates view finds identical files by content instead of by name.

Acting on the result

You can sync in either direction, update one side without deleting anything, or use two-way sync where the newer file wins. Nothing happens before you have seen the list, replaced files are backed up first and the last sync can be undone. Profiles store a folder pair with its filters so you can repeat the comparison with one click, and results can be saved as PDF, HTML or CSV.

Good to know

  • Folvane is for Windows 10 (1809+) and 11, x64 and ARM64. It works offline, needs no account and has no telemetry.
  • It compares when you start it; it is not a background sync service.
  • Two-way sync leaves files alone if both sides changed, and does not detect deletions.

Frequently asked questions

Can I compare two folders without changing anything?

Yes. Comparing only reads. Nothing is copied or removed until you review the preview and confirm a sync.

Does it compare file contents?

Yes, in byte-by-byte mode. The default quick mode uses size and date.

Can I compare folders on a USB stick or network drive?

Yes, anything Windows shows as a folder.
