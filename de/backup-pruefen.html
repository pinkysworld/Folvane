Backup prüfen unter Windows

Ein Backup, das nie geprüft wurde, ist eine Vermutung. So siehst du einfach, ob dein Backup-Ordner wirklich alles aus dem Original enthält und welche Dateien fehlen oder veraltet sind.

Die Idee

Vergleiche den Originalordner (links) mit dem Backup-Ordner (rechts). Jede Datei bekommt einen Zustand, sodass Lücken sofort auffallen, statt zwischen tausenden Dateien unterzugehen.

Schritte mit Folvane

  1. Wähle links den Originalordner und rechts den Backup-Ordner.
  2. Drücke F5 zum Vergleichen. Nach Größe und Datum dauert das Sekunden; wähle Byte für Byte, wenn du sicher sein willst, dass der Inhalt gleich ist.
  3. Lies die Zustände: Gleich heißt, das Backup ist aktuell. Nur links heißt, die Datei gibt es im Original, aber nicht im Backup. Links neuer heißt, das Backup hat eine ältere Fassung. Nur rechts heißt, das Backup enthält eine Datei, die es im Original nicht mehr gibt.
  4. Mit den farbigen Filtern zeigst du nur die Probleme, oder du suchst nach einem Namen.
  5. Doppelklick auf eine geänderte Textdatei zeigt beide Fassungen nebeneinander.
  6. Speichere das Ergebnis bei Bedarf als PDF-, HTML- oder CSV-Bericht.

Backup aktualisieren

Soll das Backup dem Original entsprechen, kann Folvane es abgleichen. Jede Aktion steht vorher in einer Vorschau, einzelne Punkte lassen sich abwählen. „Rechts aktualisieren“ kopiert neue und geänderte Dateien, ohne etwas zu löschen; „Spiegeln“ entfernt zusätzlich Dateien, die im Original fehlen. Überschriebene und entfernte Dateien werden vorher gesichert, der letzte Abgleich lässt sich im Verlauf rückgängig machen.

Ehrliche Grenzen

  • Folvane vergleicht und gleicht Ordner ab, wenn du es startest. Es plant oder führt keine Backups im Hintergrund aus. Um ein Backup aktuell zu halten, startest du den Vergleich erneut, oder du erstellst das Backup mit einem anderen Programm und prüfst es mit Folvane.
  • Ein übereinstimmender Vergleich zeigt, dass zwei Ordner dieselben Dateien enthalten. Er beweist nicht, dass sich das Backup wiederherstellen lässt, dass der Datenträger gesund ist oder dass es eine weitere Kopie an einem anderen Ort gibt.
  • Dateien, die von anderen Programmen geöffnet oder gesperrt sind, werden eventuell nicht kopiert; das Protokoll des Abgleichs zeigt Fehler.
  • Der Zwei-Wege-Abgleich erkennt keine gelöschten Dateien. Nutze „Spiegeln“, wenn Löschungen übernommen werden sollen.

Häufige Fragen

Macht Folvane automatisch Backups?

Nein. Es vergleicht zwei Ordner und gleicht sie auf Wunsch ab, mit Vorschau und Rückgängig. Eine Zeitplanung gibt es nicht.

Kann ich eine externe Festplatte oder ein Netzlaufwerk prüfen?

Ja, alles, was Windows als Ordner anzeigt. Für FAT/exFAT-Laufwerke gibt es eine Zeittoleranz bei Zeitstempeln.

Funktioniert das offline?

Ja. Folvane braucht keine Internetverbindung und kein Konto und sendet keine Daten.

Was, wenn das Backup Dateien enthält, die das Original nicht hat?

Sie erscheinen als „nur rechts“. Folvane entfernt sie nur, wenn du einen Spiegel-Abgleich wählst, der immer vorher angezeigt und gesichert wird.
